# Stage 4e: constituent gate

Protocol declared before the run; results follow in this receipt.
Authority: [5.5 start plan](../../plans/2026-10-17-item5-5-start.md#stage-4e-authorization-and-fixed-measurement-2026-10-17).

The corpus is generated by `test/constituent_corpus.py` into
`data/constituents/`: text streams, training-only trees, and separate grading
labels. Training contains 16 examples of each of adjective NPs, intransitive,
transitive and prepositional clauses, plus eight unlowered descriptions.
Evaluation holds out eight examples of each construction and eight
descriptions. Every noun occurs in both roles; determiners and lexical
combinations cross. No inflection or word-class rule is installed.
Each packed source record supplies one sentence boundary; the text has no
extra period token. Native input and annotation cover exactly the same words.

Fixed budget: 72 sentences twice (**144 presentations**, batches of four),
seed **20261010**, learning rate **.003**; start from the accepted paired
stages 1–2 checkpoint (76 prior presentations, 20/24 singleton gate).
The two epochs use seeded permutations. No additional warm-up or identity
run. Evaluation is one free pass, without annotations or optimizer, over
40 rows. Evaluation writes native occurrences; statistical learning is frozen.

Both trials retain their actual attention and compose choices. Only detached
teacher states from the captured leaves receive the annotation's compose CE,
including waits. The older reading-order lesson is excluded because it forces
its target action. Brackets are sets of source positions; reading order is
reported but is not an extra bracket gate. Dropped or duplicated words fail
complete coverage. A noun's stamp is never supplied by the labels.
Case-dependent operators receive only the reader's existing native case bank.
If a required fold has no cases, that teacher trace stops at the unavailable
target and reports it; no invented value supplies downstream teaching states.
The whole sentence still counts in the held-out gate. The lesson audit records
both reachable CE targets and these unavailable folds.

The grader observes admitted journals and the row writer. An occurrence must
be a written order-1 row whose description span matches the NP; binding need
not yet succeed. Multiple writes, duplicate occurrences, address collisions
between NPs and unexpected occurrences fail the occurrence gate. Reduction
must occur once at each annotated NP with stamps exactly 2→1. Unlowered
controls must retain all their leaves and write no individual occurrence.

| Gate | Required |
|---|---|
| Exact free brackets | ≥90% of 32 constituent sentences |
| Singular NP occurrences | ≥95% of 48 NPs, zero duplicate writes |
| Actual lowering | 48/48 NPs reduce 2→1 |
| Unlowered descriptions | 8/8 without an occurrence |
