# Item 5.5 start: occurrence, constituents and verb phases

Item 6 is accepted as a mechanism. This start records the remaining code and
its dependencies; it makes no learning claim and changes no production
mechanism. [Orders](../Orders.md) and the item-6 plan's
[§15–16 decisions](2026-10-10-item-6-stored-idea-generativity.md#15-identity-without-a-mixing-matrix-alec-2026-10-16)
govern the older [5.5 spec](../specs/2026-09-30-occurrence-tense-aspect.md).
In particular, `.when` remains the source-relative interval, mint and bind
remain distinct, and generic descriptions are not lowered merely because a
word is plural or follows `every`.

## First scoped work: stage 4e

Use the stage 4b–4d vocabulary and constructions with generated constituent
spans and teacher trees. Keep text, training annotations and held-out grading
labels separate. Include one- and two-NP clauses, adjective extensions,
transitive VPs and prepositional attachments, with the same word forms already
presented to the learner. Counterbalance the lexical combinations and NP roles;
do not install word→operator anchors or a production ordering rule.

The measurement must report free held-out bracket recovery, NP occurrence
coverage and duplicate writes, actual reference orders, closed meaning norms,
and kept programs. A singular NP counts at its order reduction, and its stored
signature is the description before the sentence fold. Order-2 descriptions
which are not lowered have no order-1 occurrence. Supplied teacher readings
are mechanism diagnostics, not passing free-reading results.

Build and check that corpus/grader before training. Then connect its explicit
annotation targets to the existing compose chooser's CE under paired
explore/keep training. Declare the fixed presentation budget and held-out gate
before the run; keep the established warm-up seed and presentation budgets.
Stop at the constituent gate if held-out brackets or occurrence coverage fail.
There is **no native identity run until stage 4e passes**.

After that gate, the carried sequence is identity matching and document-close
row pairs, VP temporal-difference teaching, direct-operand word classes, and
later order-2 kinds. Neither order-2 design is selected here. The 5.5 mechanism
work retains the spec's clock-independence, offset-independence, addressed-chain,
interleaving, preposition and surface-inverse certificates; the existing item-6
learning failures remain named in todo item 0.
