## Implemented behavior

[Forgetting.py](../../bin/Forgetting.py) runs on the host after backward and
reset at document boundaries, with an optional completed-epoch trigger.
Stateful inference runs it after a request. Stateless requests and open
sentences do not run it. Default high/low water is 90%/70%, separated by at
least 256 completed sentence presentations.

Retention value combines absolute **source trust**, idea surprise or one-step
non-deducibility, luminosity contribution, and bounded age. The new
`source_trust` buffer is separate from `c_plus`/`c_minus`; the old `trust`
accessor remains a compatibility signed-evidence read. Existing checkpoints
without source provenance load unknown zero, not inferred trust. Older
explicit scalar provenance is migrated, including a larger configured store.
Both `REL_NONE` descriptions and `REL_OPERATOR` sentence rows read their
stored surprise as utility. `REL_PARTOF` and `REL_IMPLIES` use one-step
deducibility; other relation kinds have utility 1. Conversation rows currently
share one model-level trust multiplier, so trust cannot rank those rows
against each other.

Age is rows back in a witnessing stream's retained history. Shared rows use
the youngest position; unknown legacy history has no age penalty. Both
profiles use `1 - exp(-age / forgetHalfLife)` under pressure. The retained
parameter name denotes an exponential scale. Re-witnessing does not move a
row, and retrieval does not refresh it. No new last-use or wall clock exists.
Unwitnessed rows, including estimates and `stream=-1` writes, never age:
their age stays zero until a stream witnesses them.
Trust and utility can outweigh age; there is no age-only decay in the absence
of pressure or the explicit epoch option.

Protected origins and live references preserve their content dependencies.
Wording goes before subordinate structure. Point-bearing operands can leave
a coarsened parent; relational operands cascade. Every row takes at most one
detail stage in a pass. Derivable conclusions are expendable only with a
surviving one-step proof; deleting a conclusion pins that proof, and losing a
proof raises an unselected conclusion's utility. Intrinsic *both* is not
cross-source dissonance.

Compaction retains stable addresses and per-stream order. It repairs physical
postings, DEF lookup, semantic fingerprints and expectation links. A surviving
observation can lose its forgotten estimate's provenance. Pending predictor
tensors remain unchanged and their live source rows are protected. Taxonomy
edges now record their LTM supports: loss of the last testimony removes only
an edge without an independent native definition, preserving surviving learned
coefficients and moments. Legacy edges without provenance remain native.
`clear_origin` now uses the same compaction path and retracts taxonomy edges
supported only by the cleared origin, preserving independent native support.

## Concept inventory

[ConceptForgetting.py](../../bin/ConceptForgetting.py) warns at maximum
preallocation, including the exact filling allocation. After all streams
close, it attempts to reclaim unreferenced exact redundancies: matching
order, nonempty native definition, sparse coefficients and feature groups.
The smallest meaning magnitude goes first; a stronger representative remains,
with referenced representatives preferred. Empty or merely small vectors do
not certify redundancy. Alec's review decision additionally permits unused
mints with no definition, reference/posting evidence, or sparse placement.
Two such mints need not be equivalent. Native records, definition rows,
reference/witness metadata, feature groups and even zero-valued sparse edges
exclude this route; magnitude only orders eligible candidates. Distinct
order-one individuals never merge by matching descriptions. Unreferenced
zero-relevance identity/change columns can also go.

Native records, word associations, definitions, retrieval postings, component
coordinates, frozen concepts and retained thoughts protect their targets.
The existing derived meaning uses `n/(n+4)` times a unit direction: zero with
no witnesses, growing with witnessed definedness. This is a certainty proxy,
not a calibrated probability. Form and situation coordinates do not enter
magnitude ranking when the derived meaning owner is available.

Reclaimed physical slots can be reused, but retired handles remain retired.
Fresh handles keep increasing. Sparse moments migrate by surviving edge
identity; a reused vector slot has zero gradient/moments. Reclamation credits,
retired handles, row maps and testimony provenance round-trip in the allocator
sidecar. No safe candidate means no erased concept and a visible warning.

## Limits

- A document can fill LTM before its next safe boundary. Admission still
  raises atomically; no partial graph is written and no mid-sentence deletion
  occurs. Item 3 must size the reserve for complete document transactions.
- Protected content and gradual detail loss can leave occupancy above the
  target; the report states that explicitly. Legacy taxonomy without support
  provenance is not destructively reconstructed.
- Redundancy is deliberately exact. This does not implement approximate
  semantic merging, learned consolidation, or extra truth-kind/use weights
  that the old spec proposed but Alec had not decided.
- Similarity blocks are O(n²), and a cascade can scan O(n) rows per candidate.
  Item 3's sizing work must revisit this cost beyond the default 1,024 rows.

### A. Defect: the surprise term never reaches ordinary sentence rows

`retention_values` applies the surprise-based utility only to `REL_NONE`
rows. The live write path tags an ordinary sentence as `operator`
(`REL_OPERATOR`); only a bare description is `REL_NONE`. Probe: a
three-role meaning written with surprise .05 has utility **1.0**; a
single-NP idea with the same surprise has utility .05. Under the two-truths
contract the S row *is* the idea row the spec's §3 names. Consequence under
default weights: every sentence row scores `|t| + 1 + L − age`, the live
trust is one model-level multiplier for every conversation row, so the pass
orders sentence rows oldest-first except for dissonant pairs. "Retention by
surprise" (accessible-mind test 31, the item's exit criterion) is not
implemented for sentences.
*Fix:* surprise utility for `REL_NONE` and `REL_OPERATOR` rows; one-step
deducibility for `REL_PARTOF`/`REL_IMPLIES`; 1 for other relation kinds.
One regression: two three-role rows at equal trust and age, surprise .05
versus .9, the low-surprise row is deleted first.

### B. Coverage gap: the live hook never ran on a model

No worker log of the final sweep contains `[LTM forgetting]`; every
boundary test drives `post_tick_compact`/`model_boundary` with
`SimpleNamespace` stand-ins. The wiring through a real `BasicModel` (semantic
sidecar, thought memory roots, expectation chains, taxonomy rebuild, truth
view) has not executed end to end.
*Fix:* one certificate on a real model with a small `ltmCapacity` (about 16):
two short documents; the pass fires at the first boundary and logs its
report; the second document reads and writes; a checkpoint saved after the
pass reloads with the same occupancy and counters.

### C. Decision for Alec: what counts as a reclaimable concept

The candidate reclaims only *exact* redundancies: same order, records,
definition rows and feature groups; two empty concepts are not redundant;
smallness alone never erases. Alec's instruction was "smallest concept
vectors first … make some attempt to erase only redundant concepts". Exact
duplicates will be rare, so at capacity the inventory will stay full with a
warning at every boundary.
Options: (1) keep exact-only; (2) also reclaim concepts that were minted but
never defined, referenced, posted or placed in any sparse edge, smallest
magnitude first (unrecoverable noise, nothing is lost but a handle);
(3) smallest-first among all unreferenced concepts. Recommendation: (2).
